# Hitman, a TF2 Hitsound Manager

A desktop application to manage your TF2 hitsounds.
Your hitsounds are managed at your systems `AppData` folder.  
Tested only for Windows.

## Usage Guide

Setup: Click Select TF2 Folder and navigate to your steamapps/common/Team Fortress 2/tf/custom directory.  
Import: Click Import Hitsound and select a .wav file to add to your library.  
Click to select a hitsound, adjust your Min/Max pitch preferences, and simulate a damage number. Click Play Test to hear how it sounds.  
Use Selected Hitsound to inject it directly into your TF2 custom folder and generate a hitman.cfg file under your TF2 cfg folder.  
Choose a config mode in the app if you want to force vanilla TF2 or mastercomfig behavior.  
After that, Hitman can prompt to add `exec hitman.cfg` to the selected autoexec file.  
The generated cfg contains the selected pitch values and can be exec'd from autoexec.cfg or a mastercomfig overrides autoexec file.
